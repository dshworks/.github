# dshworks

Community workshop for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) ecosystem: verified guides, plugin discovery, skills, and dev tooling.

**Not affiliated with DeepSeek.** The official repo says it best: the harness is "an idea, an official showcase, and a source of inspiration" — the ecosystem belongs to the community.

## Repos

| Repo | What | Status |
|---|---|---|
| [howto-dsh](https://github.com/dshworks/howto-dsh) | Verified field notes: traps, skills, hooks, profiles — every claim dated and sourced | live |
| registry | Machine-readable plugin index over the [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic: spam-filtered, structured JSON, open data | planned |
| create-dsh | Plugin/bundle scaffolder (`npm create dsh`) | planned |
| dsh-skills | Skills gallery — dsh reads Anthropic-format `SKILL.md` from `~/.agents/skills` | planned |

## Get your plugin discovered

1. Add the `dsh-plugin` topic to your repo — the official convention ([README](https://github.com/deepseek-ai/deepseek-harness#community-and-support)).
2. Ship a `dsh.bundle` manifest so `dsh plugin add` works ([tutorial](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/develop/basic/publish.md)).
